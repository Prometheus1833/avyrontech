# Set vizual contemporan — Cabinet de Avocatură

Imagini generate cu instrumentul ImageGen integrat, la 6 noiembrie 2026. Scene ilustrative; nu reprezintă sediul real, portretul sau clienții cabinetului. Rezoluțiile native și punctele de interes sunt în `images-v2.json`.

Fiecare fotografie are variante AVIF/WebP distincte: `*-desktop-{640,960,1280}` (4:3) și `*-mobile-{480,720}` (3:2). Nu sunt măriri artificiale; originalele PNG rămân în workspace, excluse din Git și publicare.
