# Netopia — adaptor viitor

Netopia este prezent numai în registrul de capabilități și nomenclator. Nu există cereri de rețea, stări „active” sau afirmații publice despre disponibilitate.

Pentru activare sunt obligatorii: documentația oficială curentă, mediu sandbox, adaptor separat, chei idempotente, verificare webhook, maparea stărilor, contract tests, reconciliere financiară și validarea juridică a plăților recurente. Abia după aceste controale `enabled` poate deveni adevărat.
